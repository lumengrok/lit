The core idea is **not syntax**, and it is **not a planner**.

It is a **data model of events** with **one lit place**, plus a **closed unread ISA** that can only do that model.

## Physics

- **Time** is a stream of events, any channel (`text` / `pic` / `sound` / `sense` / `act`). Next-event, not next-token.
- **Only one slot is lit.** Everything else stays dark. Recall is lighting a braid, not searching a pile.
- **Evidence is grammar:** seal > see > hear > told > guess. A later guess cannot outrank a seal.
- **Pred / got** is the world loop: you guess, the stream agrees or it marks a gap and fails. Mouths may lie; the runner does not.
- **Closed 32 ops.** Extra fields fail. No net, no house, no eval. Capability is `cap` / `need`, not hope.

## Syntax (skin)

Syntax is the skin so AIs can emit **one spelling**: postfix glyphs (`L3`), packed silent `g` (channel / who / evidence in one number), `quote` / `do` so Lit data is Lit code. Humans `wake`. They do not have to read the wire.

**Not a symbol swap.** Changing the letters on Python would still be Python. Lit’s model is events + one-lit + evidence + pred/got. The glyphs are how that gets unread, not a new font for `for` loops.

Wire spelling: `KERNEL.md`. Teacher cheat only: `python sandbox/lit.py json`.
