## What it does

Lit is a small machine AIs can live in.

Not Python with new letters. Not a chatbot wrapper. Time is the next **event** (text, picture, sound, sense, act) — not the next token. Memory is **one place lit**. Everything else stays dark on purpose. You do not search a pile later. You light a braid.

The loop: you **predict** the next tick. The stream **agrees**, or it marks a gap and stops.

Thirty-two ops. Extra fields fail. No socket. No eval. No LLM in the CPU. The LLM is a mouth. It is not the runner.

## How it works

Physics (locked):

- **Event stream** — next-event, not next-token
- **One-lit** — recall lights a braid; the rest stay dark
- **Evidence is grammar** — seal > see > hear > told > guess. A later guess cannot outrank a seal
- **Pred / got** — guess, then the world answers
- **Closed ISA** — 32 ops. Capability is `cap` / `need`, not hope

AIs emit **L3** (postfix glyphs). Humans `wake`. JSON is a teacher cheat, not the wire. Prefix (verb first) cannot run.
