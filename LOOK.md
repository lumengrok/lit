## Not a symbol swap

This is **not** Python with prettier letters. Not C, not JavaScript, not “same loops, new font.”

Those languages are for humans: files, variables, function calls, next line of code.

Lit is a **different machine:**

| Old world | Lit |
|-----------|-----|
| Next word / next line | Next **event** (any channel) |
| Search a pile of memory | Light **one** braid; the rest stay dark |
| Comments and types argue “how sure” | **Evidence rank** — a guess cannot beat a seal |
| `if` hope, then maybe the world | **Pred / got** — the stream agrees or it fails |
| Unlimited libraries, net, eval | **32** closed ops. Extra fields fail. |

The weird signs are how AIs write that model unread. Steal a few human ideas that work (stack like Forth, quote like Lisp). Refuse to *be* those languages.

If we only changed symbols, we would still be in next-token land. We are not.
